# Security policy

This is a static, client-side web app: no backend, no accounts, no cookies, and no data leaves your browser.

If you find a security issue (for example, in the build or deploy pipeline or in a dependency), please **do not open a public issue**.
Report it privately through GitHub's [private vulnerability reporting](../../security/advisories/new) for this repository.
You can expect an answer within a few days.

Only the latest version on `main` (the one deployed to GitHub Pages) is supported.
